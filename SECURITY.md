# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private advisory form:

https://github.com/a-saeedia/automation/security/advisories/new

Expect an acknowledgement within 72 hours. Include reproduction steps, the affected
commit/version, and any proof-of-concept you have.

## Out of scope

- Findings that require the attacker to already control the machine or the account
- Dependency bumps with no demonstrated exploit path
- Denial-of-service reports without a concrete impact scenario
